# /prove — 向我证明这能用

> 原文（Anthropic Claude Code 团队）："Prove to me this works."
> 中文：向我证明这能用。

不要用"我认为""应该可以"来回答，要拿出**实际运行的证据**。

## 做法

1. 确定主分支（main / master）和当前分支，列出改动涉及的功能。用户若附带了参数，只证明该功能。
2. 为每个功能设计能体现差异的验证方式，优先级：现有测试 → 新写的临时测试或脚本 → 实际启动程序操作 → 调用接口或命令行。
3. **在主分支上**运行一遍，记录结果（可以用 `git worktree add` 开一个主分支的临时副本，不要动用户当前的工作区）。
4. **在当前分支上**用完全相同的方式再运行一遍，记录结果。
5. 也要覆盖边界情况和原有功能，确认没有引入回归。
6. 结束后清理临时 worktree 和临时文件。

## 报告

| 场景 | 主分支结果 | 当前分支结果 | 结论 |
|---|---|---|---|

然后给出总结论：**已证明能用** / **部分证明** / **证明失败**。贴出关键的命令和输出作为证据。没能验证的部分要明确说出来，不要含糊带过。
